Polyomino Packer

Overview

Polyomino Packer is a Java application designed to efficiently pack polyomino shapes onto a grid. The application includes a GUI that visually demonstrates the packing process. The project aims to showcase various packing algorithms and provide a visual representation of polyomino placement.

Features

Graphical User Interface: View the grid and polyominoes in real-time.
Polyomino Shapes: Includes polyomino shapes of five or fewer units (e.g., square, L-shape).
Efficient Packing Algorithms: Implements algorithms for fitting polyominoes onto a grid.
Visualization: Displays the packing process and the final arrangement of polyominoes.
